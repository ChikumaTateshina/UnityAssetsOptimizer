# VRChat Asset Optimizer

VRChat のワールド/アバター向けの非破壊アセット最適化ツール（Unity Editor 拡張）です。

- メニュー: `Tools > VRChat Asset Optimizer > Open`
- 生成先: `Assets/VAOGenerated/<run-id>/`（原本は変更しません）
- 詳細: リポジトリの [README](https://github.com/ChikumaTateshina/UnityAssetsOptimizer) と `Documentation~/CompatibilityMatrix.md`
