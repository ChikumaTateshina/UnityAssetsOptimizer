# VRChat Asset Optimizer — 要件定義書

- 文書ID: VAO-REQ-001
- 版: 1.0（設計ベースライン）
- 作成日: 2026-11-06
- 対象: Unity Editor / VRChat Worlds・Avatars
- 状態: 実装前。SDK依存事項は対応バージョンごとに検証する。

## 1. 目的
Unity Editorでユーザーが明示的に選択した単一または複数のGameObjectと子階層に対し、テクスチャアトラス化、マテリアル統合、メッシュ・テクスチャ最適化、性能評価、VRChatモバイル派生版生成を提供する。元データを改変せず、処理前・予測・処理後の数値を比較可能にする。

## 2. 絶対条件・優先順位
**不変条件（Manual Overrideを含め解除不可）**
1. 元のアセット・Prefab・シーンオブジェクトを変更しない。生成先は別の管理領域とする。
2. 生成物を破棄することで元状態へ戻せること。元状態のスナップショットと依存参照を検証し、復元不能なら最適化を開始しない。
3. 不明・未対応・解析不能な処理は通常モードではスキップする。推測で変換しない。
4. 実行範囲は選択されたルートと子階層に限定する。外部参照を変更する必要がある処理は拒否する。
5. 予測値を実測値として表示しない。算出不能値を架空の数値で補完しない。
6. 処理はトランザクション方式。失敗時は生成途中のデータを破棄し、元の状態を維持する。
7. 公開・アップロードはユーザーの明示的な最終確認を必須とする。

優先順位: データ保全 > 復元可能性 > 機能互換性 > 外観保持 > 性能改善。FORCEは機能互換性・外観保持の自動判定のみを条件付きで緩和できる。

## 3. スコープ
### 3.1 対象
- Hierarchy上の単一/複数GameObject、選択Prefabの内容とその子階層。
- 複数選択で祖先と子孫が重複した場合は重複除去。
- World/Avatarプリセット。初期対応はVRChat SDKに対応するUnityバージョンのBuilt-in Render Pipeline。
- 選択外のアセットは読み取り解析のみ。共有アセットへの書き込み禁止。

### 3.2 対象外・初期制約
- シーン全体やプロジェクト全体の無差別な自動改変。
- 任意のカスタムシェーダーの完全自動変換保証。
- 任意のUdon/Animator/外部拡張の動作保証。
- 実機なしでのGPU時間・VRAM実測値の保証。
- VRChatの非公開SDK APIへの恒常的依存。

## 4. 機能要件
### FR-01 対象選択
選択GameObject群を明示し、処理対象の階層、外部依存、共有参照、Prefab Variant、アニメーション参照を解析する。複数選択を1つのアトラスグループにまとめるかは互換性・描画範囲を考慮して決める。

### FR-02 プリセットと詳細設定
標準プリセットは `World` と `Avatar`。各機能に個別ON/OFF、詳細パラメータ（アトラス解像度・パディング、圧縮品質、削減率、LOD閾値等）を用意する。プリセット初期値とユーザー変更値を区別する。危険度の高い処理は既定OFF。

| 機能 | World初期 | Avatar初期 | 備考 |
|---|---|---|---|
| アトラス化 | ON | ON | 互換グループのみ |
| 同一Material統合 | ON | ON | プロパティ・描画状態の等価性確認 |
| 重複Texture検出/統合 | ON | ON | 内容・Importer設定を考慮 |
| テクスチャ圧縮 | ON | ON | ターゲット別設定 |
| 自動解像度削減 | OFF | OFF | 画質影響 |
| メッシュ結合 | ON（条件付き） | OFF | 参照・Culling保護 |
| 不要頂点属性削除 | ON（検証付き） | ON（検証付き） | 使用状況が不明ならスキップ |
| Mesh Compression | ON（検証付き） | ON（検証付き） | 形状誤差を検証 |
| ポリゴン削減 | OFF | OFF | Phase 4 |
| LOD生成 | OFF | OFF | Phase 4 |
| Collider簡略化 | OFF | 対象外 | Phase 4 |
| Static Batching支援 | ON | 対象外 | 競合判定 |
| GPU Instancing支援 | ON | OFF | 競合判定 |
| Lightmap UV再生成 | OFF | 対象外 | ベイクへの影響 |
| Shader自動置換 | OFF | OFF | 専用アダプターのみ |

### FR-03 アトラス・マテリアル
対応シェーダーと互換Materialをグループ化し、テクスチャチャンネルを整合させてアトラスを生成する。UV変換、境界頂点の分離、SubMesh・Materialスロットの再構成を行う。UV repeat/mirror、特殊ブレンド、動的プロパティ、マスク・ノーマル等を解析し、未対応ならスキップする。ライトマップUV等の別チャンネルは保持する。

### FR-04 メッシュ・テクスチャ最適化
重複検出、プラットフォーム別圧縮、頂点属性整理、条件付きメッシュ結合、ポリゴン削減、LOD、Collider簡略化、Batching/Instancing設定支援を提供。変更が有益かつ安全であることを個別に判定する。

### FR-05 解析・事前予測・事後測定
最適化前に現在値と予測値を提示する。最適化後に結果値を提示する。指標: Mesh数、Renderer数、ユニークMaterial数、Materialスロット数、SubMesh数、三角形数、頂点数、Texture数、ディスク容量、GPUテクスチャメモリ推定、Draw Calls、SetPass Calls、Batches、GPU/CPU描画時間（取得可能な場合）。
- `確定計算`、`推定`、`実測`、`取得不可`を明示する。
- Draw Calls等はカメラ、可視性、描画パス、Batching、照明、対象環境を併記する。
- 選択オブジェクトだけに帰属不能なDraw Callsは、隔離プレビューの測定値またはシーン差分参考値として明記する。
- 予測不可項目は「算出不可」とし、数値の提示要件を偽の精度で満たさない。
- 前後比較の測定条件を可能な限り固定し、予測誤差を記録する。

### FR-06 Avatar Performance Rank
AvatarプリセットではPC/Android/iOSの各対応環境について、VRChat公式評価の現在値・予測値・処理後値を表示する。評価項目別の値、閾値、超過量、ボトルネック、目標ランクとの差を示す。SDKの公式評価器を公開された安定APIで利用できる場合は優先し、不可の場合はSDK版に対応した閾値DBに基づく**独立推定**と明示する。SDKビルド処理で変化するAvatar構成は、ビルド後評価が取得できない限り「評価不完全」とする。閾値を固定値として仕様書に埋め込まない。

### FR-07 Manual Override（隠しモード）
通常画面では非表示。専用Editorメニューからユーザー別に有効化。各機能は `OFF/AUTO/FORCE`。FORCEは個別の確認・リスク表示・監査ログを要求し、互換性や外観差のリスクを受容して処理する。ただし原本保全・復元保証・処理境界・トランザクション・書き込み制約は解除不可。技術的に実行不能な対象はFORCEでも拒否。

### FR-08 Android/iOS変換（Phase 5）
PC用選択アセットからAndroid版/iOS版の**別個の派生Prefabと依存アセット**を生成する。World/Avatarごとに、プラットフォーム能力DB、Texture Importer設定、Shader Adapter、Mesh/LOD、コンポーネント互換性、SDKビルド検証を適用。VRChatが当該プラットフォームをサポートすることをSDK・公式仕様で確認する。Unityでビルド可能でもVRChat対応と断定しない。変換結果は `完了（SDK検証済）/部分変換/変換不可`、実機検証は別ステータス。元PC版は維持する。自動アップロードは既定OFF。

### FR-09 ログ・レポート
対象、SDK/Unity版、プリセット、実行機能、判定根拠、スキップ理由、FORCE承認、変更アセット、前/予測/後数値、検証結果、復元状態を機械可読JSONと人間向けMarkdownで出力する。

### FR-10 復元
処理前のアセット内容・GUID・参照・Hierarchy・コンポーネント・Prefab対応を記録する。生成物を消去し、元の参照先を復帰できる。外部から原本が変更・削除された場合は復元を保証できないため、独立スナップショットから復元可能か検証し、欠落時は失敗と明示する。Unity Undoのみには依存しない。

## 5. 非機能要件
- 安全性: fail-closed、冪等な再実行、例外時ロールバック。
- 再現性: 同じ入力・設定・ツール版・SDK版なら同じ生成結果を目標とし、非決定的な工程を記録。
- 保守性: 処理プラグイン、Shader Adapter、Platform Capability DBを分離。
- UX: 解析→計画→事前比較→確認→生成→検証→事後比較。危険処理は説明付き。
- 性能: 大規模入力でもEditorの進捗・キャンセルを提供し、キャンセル時は原本無変更。
- 権利: 第三者アセットの再配布権を本ツールは付与しない。外部ライブラリのライセンスを確認。

## 6. 受け入れ基準
1. 原本アセットのバイト列・GUID・シーン保存状態が処理前後で変わらないこと（意図的に生成した別ファイルを除く）。
2. 最適化の成功・失敗・キャンセル・FORCEの各経路で原本が保護されること。
3. 未対応シェーダー・未知コンポーネント・外部参照を持つ対象が通常モードでスキップされ、理由が残ること。
4. Dry Run前に現在値、Dry Run後かつ本実行前に予測値が表示されること。算出不可は明示すること。
5. 最適化後に実測可能な指標を再計測し、測定環境と共に比較表示すること。
6. AvatarのランクはPC/Android/iOS別にSDK由来か推定かを識別し、未対応SDK版では正確な公式ランクと称さないこと。
7. Android/iOS派生アセットがPC版と独立し、SDKビルド検証の成否が記録されること。
8. 選択外アセットが書き換えられないこと。
9. 復元スナップショット破損時は最適化を開始しないこと。

## 7. 段階別実装
- Phase 1: 対象選択、解析基盤、非破壊・復元、アトラス化、Material統合、基本現在値/予測値/結果値。
- Phase 2: Texture圧縮・重複統合、Mesh結合、頂点属性整理、詳細レポート。
- Phase 3: 高度なプランナー、描画計測、予測・検証、Shader Adapter拡張、Manual Override完成、Avatar Rank解析。
- Phase 4: ポリゴン削減、LOD生成、Collider簡略化。
- Phase 5: Android/iOS能力DB、変換アダプター、派生版生成、SDK/実機検証支援、公開連携。

## 8. 未確定・実装時検証事項
VRChat SDK/Unityの対象バージョン、iOSサポート状態、公開されるPerformance Rank評価API、対応モバイルShader一覧、SDKビルド/アップロードAPI、Modular Avatar/VRCFury等のビルド時変換へのアクセス、プラットフォーム別閾値、GPU計測の可用性。**検証完了まで機能を有効化しない。**
